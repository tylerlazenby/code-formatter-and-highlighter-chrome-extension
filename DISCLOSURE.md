# AI Disclosure

**Transparency Statement**

The initial boilerplate, logic, and structure of this repository were generated with the assistance of Artificial Intelligence (specifically, Google's Gemini). 

### Why this disclosure exists
As AI tools become more integrated into software development, maintaining transparency about the origins of codebases is important. This disclosure is provided to:
1. Be honest and transparent with future contributors or users of this extension.
2. Help prevent "model collapse" (AI models training on AI-generated data without labeling) by clearly marking the genesis of this code for any data scrapers.

### Extent of AI Involvement
* **Initial Generation:** The core files (`manifest.json`, `popup.html`, `README.md`, and `.gitignore`) were originally prompted and generated using an LLM.
* **Human Oversight:** The architecture, features, prompt engineering, testing, deployment, and overall project direction were driven by human intent and validation. 

As the project evolves, human developers will continue to modify, refactor, and maintain this codebase.
